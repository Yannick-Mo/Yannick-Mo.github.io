📘 标准Transformer（原版）完整架构流程笔记

适用场景与宏观哲学

  • 任务类型：Seq2Seq（如英译中）。输入是一整个源句子（如英文），输出是逐个生成的目标句子（如中文）。
  • 宏观三件套：
    1. 编码器（Encoder）：**双向（Bi-directional）**读取整个源句子，将其提炼为"记忆向量"。
    2. 解码器（Decoder）：**自回归（Auto-regressive）**从左到右生成目标句子，生成时通过"交叉注意力"不断查阅编码器的记忆。
    3. 共享桥梁：解码器最后一层输出 -> 线性层（Linear）-> Softmax -> 输出概率分布。

第一阶段：输入嵌入与位置编码（Input Preparation）

这一步编码器和解码器完全一致，但输入内容不同（源语言 vs 目标语言）。

  1. 词元嵌入（Token Embedding）：

    • 将输入Token ID转化为密集向量 X_emb，形状 (Batch, Seq_Len, d_model)（d_model 通常为512或1024）。
    • 乘以 sqrt(d_model) 进行缩放（原论文操作，为了平衡嵌入与位置编码的量级）。

  2. 位置编码（Positional Encoding）——这里是标准写法，而非RoPE：

    • 不使用可学习嵌入，而是直接加法加入固定公式计算的向量。
    • 公式：对于位置 pos 和维度索引 i：
      • 偶数位：PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
      • 奇数位：PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
    • 最终输入向量：X = X_emb + PE（形状不变）。

第二阶段：编码器（Encoder）—— 理解源语言

前置设定

假设输入到这一层的张量为 X，形状为 (B, S, d_model)：

  • B：批次大小
  • S：源语言序列长度（比如句子有10个词）
  • d_model：模型维度（原论文为512）

关键点：编码器是双向的，即计算某个位置的注意力时，它可以看到序列中所有其他位置（包括它自己以及后面的词），不存在掩码。

子层一：多头自注意力子层（Multi-Head Self-Attention Sub-layer）

本子层遵循"核心注意力 → Add → LayerNorm"的流程。

步骤 2.1：多头自注意力（Multi-Head Self-Attention）

做什么：让每个位置的信息去"询问"所有位置，并聚合全局上下文。

拆解动作：

  1. 生成 Q、K、V
    X 会分别乘以三个权重矩阵 W_Q, W_K, W_V（每个形状均为 d_model × d_model），得到 Q、K、V，形状均为 (B, S, d_model)。
    这里 Q、K、V 来自同一个输入 X，所以叫"自"注意力。

  2. 拆分为多头
    将 d_model 沿特征维度切分成 h 个头（原论文 h=8，每头维度 d_k = d_model / h = 64）。
    此时 Q、K、V 的形状变为 (B, h, S, d_k)。每个头独立负责一个子空间，去捕捉不同层面的关系（语法、语义、位置等）。

  3. 计算注意力分数
    对每个头，计算 Q × K^T（最后两维矩阵乘法），得到分数矩阵，形状 (B, h, S, S)。
    其中第 i 行第 j 列的值表示：第 i 个位置对第 j 个位置的关注强度（未归一化）。

  4. 缩放（Scaling）
    将分数除以 √d_k（即√64=8）。目的：防止点积值过大，导致后续 Softmax 进入梯度极小的饱和区。

  5. Softmax 归一化
    对分数矩阵的每一行（即每个查询位置）做 Softmax，使每一行的注意力权重之和为 1。
    此时矩阵中每个值表示：当前查询位置应该给每个键位置分配的注意力比例。因为没有掩码，所有位置的权重都参与计算。

  6. 加权求和
    将权重矩阵与 V 相乘：Attention_Out = Softmax(···) × V，形状回到 (B, h, S, d_k)。
    这一步得到的是每个头加权聚合后的特征。

  7. 合并多头
    将 h 个头在特征维度上拼接（Concat），得到 (B, S, d_model)，再乘以输出投影矩阵 W_O（d_model × d_model），得到最终的多头输出 Attn_Out，形状 (B, S, d_model)。

此时得到的 Attn_Out：每个位置的向量都已经融合了全序列其他位置的信息，但它是线性变换后的结果，还没与原始输入交互。

步骤 2.2：残差连接（Add）

做什么：将原始输入 X 与刚刚算出的 Attn_Out 直接相加：X = X + Attn_Out。

为什么必须这么做：

  • 梯度高速公路：反向传播时，梯度可以直接通过"加"这条路径流回浅层，避免深层网络梯度消失。
  • 保留原始信息：注意力层可能过度拟合或丢失某些局部特征，加上原始 X 相当于给模型一个"保底"选项——如果注意力没用，它至少还能保留输入本身。

注意：原版 Transformer 在这里是先 Add 后 LayerNorm（即 Post-Norm 结构），这与现在流行的 Pre-Norm（先 LN 后 Add）顺序相反。Post-Norm 训练时对学习率更敏感，但原论文就是这么设计的。

步骤 2.3：层归一化（LayerNorm）

做什么：对 X = X + Attn_Out 这个结果做归一化。

细节：

  • 对每个样本的每个位置，计算其 d_model 维特征上的均值和方差。
  • 然后用公式 (X - mean) / √(var + ε) 标准化，再乘以可学习的缩放参数 γ 和平移参数 β（形状均为 d_model）。
  • 输出形状仍为 (B, S, d_model)。

它与 BatchNorm 的区别：LayerNorm 在特征维度上独立归一化，不受批次大小和序列长度影响，非常适合变长序列（NLP 场景）。
作用：将数据分布拉回均值为 0、方差为 1 的稳定区间，让后续 FFN 层的输入不至于过于爆炸或萎缩，加速收敛。

子层二：前馈网络子层（Feed-Forward Network Sub-layer）

本子层遵循"核心 FFN → Add → LayerNorm"的流程。注意，此处的输入 X 已经是子层一（经过 Add+LN）的输出。

步骤 2.4：前馈网络（FFN）

做什么：对每个位置独立地进行两次线性变换，中间夹一个 ReLU 激活。这是逐位置（Position-wise）的全连接层。

公式：FFN(X) = ReLU(X * W_1 + b_1) * W_2 + b_2

张量变化：

  • 第一层：X (B, S, 512) 乘以 W_1 (512 × 2048)，加上偏置，得到 (B, S, 2048)。内层维度扩张到 4 倍，这是原论文的经典设置。
  • 激活函数：ReLU 将负数全部置为 0，引入非线性，让模型能拟合复杂函数。同时 ReLU 计算简单，能缓解梯度消失。
  • 第二层：(B, S, 2048) 乘以 W_2 (2048 × 512)，加偏置，投影回 (B, S, 512)。

关键点：这个 FFN 对每个位置（S 个）独立运算，参数在所有位置共享。它相当于在注意力层"全局混合"之后，再对每个位置做"深度加工"——注意力负责"看哪里"，FFN 负责"想什么"（提炼更高阶的特征）。

步骤 2.5：残差连接（Add）

做什么：将步骤 2.3 归一化后的输出（即 LayerNorm( X + Attn_Out )）与 FFN 的输出相加：X = X + FFN_Out。

这里的 X 实际上是经过第一次残差+归一化后的结果（即子层一的输出），而不是最原始的输入。
作用：与步骤 2.2 相同，给 FFN 层也提供一条梯度直通捷径，确保即使 FFN 学习效果不佳，信息仍能无损传递。

步骤 2.6：层归一化（LayerNorm）

做什么：对步骤 2.5 相加的结果再次做 LayerNorm，得到本编码器层的最终输出，形状仍为 (B, S, d_model)。

这是 Post-Norm 的典型收尾：每个子层（Attention 或 FFN）都遵循"先 Add 后 Norm"。
至此，一个编码器层的全部计算结束。

额外补充（原论文中未列在你这张表里，但实际存在的细节）

  • Dropout：在每一步残差相加之前（即 Attn_Out 和 FFN_Out 输出后），都会施加 Dropout（通常 p=0.1），用于正则化，防止过拟合。
  • 位置编码：在进入第一个编码器层之前，输入词嵌入已经加上了位置编码（正弦/余弦或可学习）。但每层内部不再额外加位置信息，因为多头注意力本身是置换不变的（打乱顺序点积结果不变），位置信息全靠输入时的那一次注入。

这一层的最终产出与下游关系

本层输出 X 会作为下一层编码器的输入，重复上述 6 次。
当所有 6 层跑完后，最终得到的张量被称为 Encoder_Memory，形状 (B, S_src, d_model)。
它的每一行都包含了源语言句子中该词与所有其他词交互后的全局上下文表示。
这个 Memory 将作为"钥匙"和"值"（即 K 和 V），送入解码器的**交叉注意力（Cross-Attention）**层，让解码器在生成目标语言时，能够"查阅"整个源句子的信息。

第三阶段：解码器（Decoder）—— 生成目标语言

前置设定

  • 解码器输入：不是原始目标句子，而是**目标句子往右偏移一位（Shifted Right）**的嵌入 + 位置编码。比如要翻译"I love you"，输入是"<BOS> I love"（<BOS>是起始符），目标是预测"I love you <EOS>"。这样第 t 个位置的输入，恰好对应第 t-1 个位置的真实词，强行建立了因果依赖。
  • 张量：记本层输入为 X_dec，形状 (B, T, d_model)，其中 T 是目标序列当前长度（训练时是整句并行，推理时逐个增长）。
  • 记忆：编码器最终输出的 Encoder_Memory 形状 (B, S, d_model)，在整个解码过程中只读不变。

核心灵魂：解码器是**自回归（Autoregressive）**的——生成目标语言时，当前位置只能看到它自己以及之前已生成的位置，绝对不能偷看未来的词。这是它和编码器最根本的区别。

解码器同样堆叠 N=6 层，每一层都按以下三个子层串行处理（每个子层都遵循"先 Add 后 LayerNorm"的 Post-Norm 结构）。

子层一：带掩码的多头自注意力子层（Masked Multi-Head Self-Attention Sub-layer）

本子层遵循"核心注意力 → Add → LayerNorm"的流程。

步骤 3.1：带掩码的多头自注意力（Masked Multi-Head Self-Attention）

做什么：让目标语言内部各个位置互相看，但必须戴上"因果掩码（Causal Mask）"，确保第 i 个位置只能看到 0 到 i 的位置，看不到 i+1 及以后。

拆解动作：

  1. 生成 Q、K、V：和编码器一样，X_dec 分别乘以当前子层的W_Q, W_K, W_V，得到 Q、K、V，形状均为 (B, T, d_model)。拆成 h 个头后，形状为 (B, h, T, d_k)。

  2. 计算未缩放分数：Q × K^T，得到分数矩阵形状 (B, h, T, T)。
    此时第 i 行第 j 列，代表目标序列第 i 个位置对第 j 个位置的原始关注度。

  3. 应用上三角掩码（关键步骤）：
    生成一个 (T, T) 的上三角矩阵（对角线以上为 1，含对角线及以下为 0）。
    将这个矩阵中为 1 的位置（即未来位置 j > i）的分数，替换为 -inf（负无穷）。
    为什么是负无穷：因为下一步要做 Softmax，-inf 经过 e^(-inf) = 0，这些位置的注意力权重就会变成绝对的 0，相当于物理上切断视线。
    而对角线及以前的位置（j ≤ i）原封不动，正常可见。

  4. 缩放 + Softmax：除以 √d_k 后，对每一行做 Softmax。由于未来位置是 0，权重只分配到当前及过去的位置上，总和依然为 1。此时第 i 行的权重分布，只代表"我（第 i 个词）如何看待我和我之前的所有词"。

  5. 加权求和 + 合并多头：乘以 V，再拼接并过 W_O，得到 Masked_Attn_Out，形状 (B, T, d_model)。

设计动机：这是保证"自回归"特性的物理屏障。训练时虽然并行输入整句，但通过这个掩码，每个位置的梯度只依赖于前文，等效于逐个生成时的状态，让模型学会根据历史推未来。

步骤 3.2：残差连接（Add）

做什么：将原始输入 X_dec 与 Masked_Attn_Out 直接相加：X_dec = X_dec + Masked_Attn_Out。

作用：与编码器相同，保留原始路径，防止自注意力层破坏已经学好的低层特征，同时提供梯度直通捷径。

步骤 3.3：层归一化（LayerNorm）

做什么：对步骤 3.2 的相加结果在 d_model 维度上做层归一化，得到新的 X_dec，形状不变。

作用：稳定数据分布，为下一个子层（交叉注意力）提供标准化输入。

子层二：交叉注意力子层（Cross-Attention Sub-layer，也叫编码器-解码器注意力）

本子层遵循"核心注意力 → Add → LayerNorm"的流程。这是解码器独有的核心模块，也是连接编码器和解码器的关键纽带。

步骤 3.4：交叉注意力（Cross-Attention）

做什么：用解码器自己的状态作为"查询（Query）"，去编码器输出的 Memory 中"检索"最相关的源语言信息，作为"键（Key）“和"值（Value）"。

拆解动作：

  1. 生成 Q（来自解码器）：将上一步归一化后的 X_dec（形状 (B, T, d_model)）乘以当前子层的W_Q，得到 Q，形状 (B, T, d_model)。这里的 Q 代表"我想问编码器什么问题”。

  2. 生成 K 和 V（来自编码器）：将编码器最终记忆 Encoder_Memory（形状 (B, S, d_model)）分别乘以当前子层的W_K 和 W_V（注意这两组权重与子层一中的 W_K, W_V 是独立不共享的），得到 K 和 V，形状均为 (B, S, d_model)。
    这里的 K 代表"源语言所有位置的特征索引"，V 代表"源语言所有位置的具体内容值"。

  3. 拆分为多头：Q 拆为 (B, h, T, d_k)，K 和 V 拆为 (B, h, S, d_k)。注意 Q 的长度是 T（目标长度），K/V 的长度是 S（源长度），二者不一定相等！

  4. 计算注意力分数：Q × K^T，得到分数矩阵形状 (B, h, T, S)。
    矩阵中第 i 行第 j 列，表示目标语言第 i 个位置，对源语言第 j 个位置的关注强度。

  5. 缩放 + Softmax：除以 √d_k 后，对分数的每一行（即每个目标位置）做 Softmax。这里没有任何掩码，因为目标语言的某个词去关注源语言的任意位置（无论前后）都是合理且允许的，不存在"泄露未来"的问题（源语言全文已知）。

  6. 加权求和 + 合并多头：将权重矩阵与 V（源语言内容）相乘，得到 (B, h, T, d_k)，再拼接并过输出投影 W_O，得到 Cross_Attn_Out，形状 (B, T, d_model)。

设计动机：这一步本质是"软对齐"（Soft Alignment）。比如翻译英译中，当解码器生成"苹果"这个词时，Q 会去 K 里检索"apple"，并给对应位置的 V 分配高权重，从而把"apple"的语义特征提取过来。它让解码器在生成每一个目标词时，都能动态地、有选择性地翻阅整本源语言"词典"。

步骤 3.5：残差连接（Add）

做什么：将子层一的输出（即步骤 3.3 归一化后的 X_dec）与 Cross_Attn_Out 直接相加：X_dec = X_dec + Cross_Attn_Out。

设计逻辑：这里的 X_dec 代表着"我基于前文对自己的理解"，现在加上从源语言检索来的外部信息，实现了"内外结合"。

步骤 3.6：层归一化（LayerNorm）

做什么：对步骤 3.5 的相加结果做层归一化，得到新的 X_dec，形状 (B, T, d_model)。

作用：为最后一个子层（FFN）提供稳定输入。

子层三：前馈网络子层（Feed-Forward Network Sub-layer）

本子层遵循"核心 FFN → Add → LayerNorm"的流程。

步骤 3.7：前馈网络（FFN）

做什么：和编码器完全相同，对每个位置独立做非线性变换，加深特征抽象。

公式：FFN(X) = ReLU(X * W_1 + b_1) * W_2 + b_2

张量变化：

  • 第一层：X_dec (B, T, 512) → (B, T, 2048)，维度扩至 4 倍。
  • ReLU 激活，引入非线性。
  • 第二层：(B, T, 2048) → (B, T, 512)，投影回原维度。

关键点：它和交叉注意力输入是串联关系，而不是并联。先"查资料"（交叉注意力），再"写总结"（FFN），逻辑上非常顺畅。此时 FFN 同时基于"我已经写了什么（历史）“和"源语言说了什么（对齐信息）“来做统一的深度加工。

步骤 3.8：残差连接（Add）

做什么：将子层二的输出（即步骤 3.6 归一化后的 X_dec）与 FFN_Out 直接相加：X_dec = X_dec + FFN_Out。

作用：给 FFN 层提供梯度直通捷径，确保即使 FFN 学习效果不佳，信息仍能无损传递。

步骤 3.9：层归一化（LayerNorm）

做什么：对步骤 3.8 的相加结果做层归一化，输出本解码器层的最终结果，形状 (B, T, d_model)。

至此，一个解码器层的全部计算结束。

本层完成后的流向与跨层细节

这一层的输出会作为下一层解码器的输入，重复上述 6 次。注意：每一层解码器在做交叉注意力时，用的都是同一份 Encoder_Memory（来自顶层编码器），但每层都有自己独立可学习的 W_Q, W_K, W_V 投影矩阵，所以每层对源语言的"检索方式"可以不同——浅层可能关注词性，深层可能关注语义逻辑。

最终输出与生成（6 层全部结束后）

  • 第 6 层解码器输出形状 (B, T, d_model)。
  • 将其送入一个线性层（Linear），将维度从 d_model 映射到 目标词表大小 V_tgt（比如 3 万），得到 (B, T, V_tgt) 的 logits 分数。
  • 最后接一个 Softmax，将分数转为概率分布，选择概率最高的词作为当前时刻的预测输出。

额外补充：训练与推理时的关键差异

  • 训练时（Teacher Forcing）：目标整句已知，一次性输入完整偏移序列，利用掩码实现并行计算，所有位置的 Loss 同时算出，效率极高。
  • 推理时（自回归生成）：只能输入 <BOS>，生成第一个词；然后把第一个词拼进输入，生成第二个词；以此类推，直到生成 <EOS>。每生成一个词，都要重新跑一遍整个解码器前向传播（但缓存机制 K/V Cache 可大幅加速，这是工程优化的重点）。

第四阶段：输出生成（Output Projection）

解码器6层全部跑完后：

  1. 得到最终隐藏状态 X_final（形状 B, T_target, d_model）。
  2. 线性投影（Linear）：Logits = X_final * W_Proj^T，将 d_model 映射回 目标词表大小（Vocab_Target）。
  3. Softmax：对 Logits 沿最后一维取 Softmax，得到每个位置的概率分布。
  4. 取最高概率：Predicted_Token = argmax(Logits)，得到当前步预测的词。

第五阶段：训练时的掩码（Mask）详解（极易混淆）

层的位置 掩码类型 具体操作
编码器自注意力 无掩码（Padding Mask除外） 所有词可以看到所有词。例如 [我, 爱, 你] 中，“爱"可以同时看到"我"和"你”。
解码器掩码自注意力 因果掩码 + Padding掩码 [<SOS>, I, love, you] 中，“love"只能看到 <SOS> 和 I，看不到 you（上三角设为 -inf）。
解码器交叉注意力 仅 Padding掩码（无因果掩码） Q（目标端）可以无条件地查看 K/V（源端）的所有位置。源端全部可见，不需要遮罩未来（因为源端没有"未来"概念）。

第六阶段：训练目标与损失（Loss）

  • 标签：原始目标句子（未右移的 Ground Truth）。
  • 损失函数：交叉熵损失（Cross-Entropy Loss）。
  • 计算方式：仅计算目标句子有效词元（忽略 <PAD>）的负对数似然。不涉及解码器输出端的任何额外辅助损失（原版没有MTP）。

第七阶段：推理（Inference）时的解码差异

  • 训练：并行输入完整的 [<SOS>, 词1, 词2, ...]（Teacher Forcing）。
  • 推理：无法并行。解码器输入只有 <SOS>，输出第一个词；然后将 <SOS> + 第一个词作为新输入，再输出第二个词……循环往复（自回归生成），直到输出结束符 <EOS>。
