Makefile 完全教程：自动化 C/C++ 编译流程

从最简示例到进阶技巧，系统讲解 Makefile 规则、变量、自动变量、模式规则、伪目标、自动生成依赖、多线程编译、条件编译等核心用法

2026-06-14
阅读时长: 4 分钟

Makefile 是一套自动化编译规则，配合 make 工具可替代手动敲 g++ 命令，尤其适合多文件、复杂项目的编译管理。make 会解析 Makefile 中的规则，自动检测文件更新（仅重新编译修改过的文件），大幅提升开发效率。

一、基础认知：Makefile 核心作用

  • 自动化：替代手动执行 g++ -c/g++ -o 等命令，一键编译；
  • 增量编译：仅重新编译「修改过的源文件」或「依赖变化的文件」，节省时间；
  • 统一管理：集中定义编译参数（如 -Wall、-std=c++11）、库依赖、输出路径等。

二、最简 Makefile：从 0 到 1

1. 单目标最简版 

1
2

main: main.cpp func.cpp
	g++ main.cpp func.cpp -o main -Wall -std=c++11

执行 make：

1

g++ main.cpp func.cpp -o main -Wall -std=c++11

2. 核心规则解析

Makefile 的核心是「规则（Rule）」，格式为：

1
2

目标(target): 依赖(prerequisites)
	命令(command)  # 注意：命令前必须是 Tab 键，不能用空格！

make 执行逻辑：

  1. 检查目标文件是否存在——若不存在则执行命令；
  2. 若存在，对比目标和依赖的修改时间——若依赖更新则重新编译，否则提示 up to date。

3. 优化：拆分目标文件（增量编译）

最简版修改任意 .cpp 都会全量编译。优化为「先编译 .o 再链接」：

1
2
3
4
5
6
7
8

main: main.o func.o
	g++ main.o func.o -o main -Wall -std=c++11

main.o: main.cpp
	g++ -c main.cpp -o main.o -Wall -std=c++11

func.o: func.cpp
	g++ -c func.cpp -o func.o -Wall -std=c++11

此时修改 func.cpp 后执行 make，仅重新编译 func.o 再链接。

CXX = g++
CXXFLAGS = -Wall -g -std=c++11
LDFLAGS =
TARGET = main
OBJS = main.o func.o

$(TARGET): $(OBJS)
	$(CXX) $(OBJS) -o $(TARGET) $(LDFLAGS)

main.o: main.cpp
	$(CXX) -c main.cpp -o main.o $(CXXFLAGS)

func.o: func.cpp
	$(CXX) -c func.cpp -o func.o $(CXXFLAGS)

$(变量名) 引用变量，变量名通常大写。

3. 模式规则：批量处理同类型文件 

1
2

%.o: %.cpp
	$(CXX) -c $< -o $@ $(CXXFLAGS)

%.o: %.cpp 表示「任意 .o 文件依赖同名的 .cpp 文件」，自动编译所有 .cpp。

CXX = g++
CXXFLAGS = -Wall -g -std=c++11
TARGET = main
OBJS = main.o func.o
DEPS = $(OBJS:.o=.d)

.PHONY: all clean

all: $(TARGET)

-include $(DEPS)

$(TARGET): $(OBJS)
	$(CXX) $^ -o $@ $(CXXFLAGS)

%.o: %.cpp
	$(CXX) -c $< -o $@ $(CXXFLAGS) -MMD -MP

clean:
	rm -rf $(TARGET) $(OBJS) $(DEPS)
  • -MMD：生成 .d 文件记录头文件依赖；
  • -include：导入依赖规则，修改头文件后自动重新编译。

BUILD_DIR = build
TARGET = build/main
OBJS = build/main.o build/func.o

$(BUILD_DIR):
	mkdir -p $(BUILD_DIR)

$(TARGET): $(OBJS) | $(BUILD_DIR)
	$(CXX) $^ -o $@ $(CXXFLAGS)

build/%.o: %.cpp | $(BUILD_DIR)
	$(CXX) -c $< -o $@ $(CXXFLAGS) -MMD -MP

clean:
	rm -rf $(BUILD_DIR)

| $(BUILD_DIR) 为「顺序依赖」，先创建目录再编译。

七、常见问题

  1. Tab 键问题：命令前必须是 Tab，否则报错 missing separator；
  2. 变量引用：用 $(VAR)，非 $VAR（$@ 等自动变量是特例）；
  3. 新增文件未编译：更新 OBJS 列表或用 wildcard 自动匹配；
  4. 头文件路径：用 CXXFLAGS += -I ./include；
  5. 链接库：用 LDFLAGS += -L ./lib -lpthread。

总结

Makefile 核心掌握几点即可应对 90% 的 C++ 项目：

  1. 规则格式：目标: 依赖 + Tab + 命令；
  2. 变量：自定义变量（CXX/CXXFLAGS）+ 自动变量（$@/$^/$<）；
  3. 模式规则：%.o: %.cpp 批量编译；
  4. 伪目标：.PHONY 声明 all/clean；
  5. 增量编译：拆分 .o + 自动生成依赖（-MMD）。
